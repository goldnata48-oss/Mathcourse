Памятка по проекту Mathcourse (актуально)
=========================================
Запуск локально:
    node start-server.ps1      (или любой статический сервер из корня)
Сборка production-бандла:
    node build.js              (пишет dist/index.html + dist/sw.js)
Проверка живого сайта:
    node .checklive.js
Деплой (production, REST API):
    node mc-deploy.js          (branch обязательно НЕ указывать)

Сайт: https://roaring-melba-8c60da.netlify.app/


Что это за проект
-----------------
Одностраничное SPA — образовательная платформа «Математика 10-11» для
подготовки к НМТ. Двуязычная (RU/UA), с PWA-оффлайном.

Архитектура (после рефакторинга)
--------------------------------
Mathcourse/
  index.html              разметка (без инлайн-кода)
  styles.css              основные стили
  theme.css               light/dark + возрастные палитры (data-grade)
  i18n.js                 переводы RU/UA
  lessons.js              данные уроков + мини-проверки
  trainer.js              генераторы задач (LEVEL_DEFS, 68 тем)
  app.js                  state, навигация, рендеринг, прогресс
  sw.js                   service worker (кэш app shell)
  manifest.webmanifest    PWA-манифест
  build.js                сборка бандла в dist/
  .checklive.js           e2e-проверки живого сайта

Уже реализовано
---------------
- Разбиение монолита на модули; index1.html удалён.
- Безопасный разбор ответов (без Function()/eval).
- PWA: service worker, кэш app shell, оффлайн, иконки.
- SEO/шаринг: meta description, Open Graph, favicon, og-иконка.
- Темы light/dark и возрастные палитры (1-4, 5-9, 10-11).
- Поиск по урокам и формулам; избранные формулы (закладки).
- Навигация «назад/вперёд» между уроками.
- Прогресс-бар модуля; отметка «урок пройден».
- Прогресс мини-проверок: бейдж на уроке + счётчик в сайдбаре
  (localStorage mc_mini), сохраняется между сессиями.
- Итоговые тесты модулей генерируются автоматически (20 минут).
- Тренажёр: 68 тем, у каждой topic/format/solution (разбор ответа).
- Экспорт формул/конспекта в PDF (клиентский генератор).
- Маскот «Квантик» с контекстными подсказками.
- Деплой задокументирован и автоматизирован (REST, mc-deploy.js).

Оставшиеся рекомендации
-----------------------
P1 — Контент (главная цель платформы):
  1. Больше задач НМТ-формата в тренажёре (в т.ч. с параметром).
  2. Разборы НМТ-тестов прошлых лет (пошаговые решения).
  3. Видео-вставки (YouTube) для сложных тем.

P2 — Прогресс и геймификация:
  4. История ответов мини-проверок и тренажёра (динамика по датам).
  5. Сброс прогресса мини-проверок/уроков в настройках.
  6. Достижения/серии (streak) для мотивации.

P3 — UX:
  7. Печать/экспорт отдельного урока в PDF.
  8. Print-стили (аккуратная вёрстка при печати урока).
  9. A11y-аудит (фокус, aria, контраст).
  10. E2E-проверки мини-проверок в .checklive.js (расширять по мере роста).

P4 — Инфраструктура:
  11. Починить deploy-netlify.ps1 (npx/netlify-cli отваливается;
      используем REST mc-deploy.js).
  12. Вынести аудит-скрипты (runtime-audit, gens-semantic, mixscan)
      в репозиторий как npm-скрипты/CI.

Общая оценка
------------
Платформа в хорошем состоянии: чистая модульная архитектура, i18n,
безопасный ввод, PWA, продуманный контент и покрытие проверками.
Ключевые направления дальше — наполнение НМТ-контентом и развитие
прогресса/геймификации.
