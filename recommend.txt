Памятка по проекту Mathcourse (актуально)
=========================================
Запуск локально:
    node start-server.ps1            (или любой статический сервер из корня)
Сборка production-бандла:
    npm run build                    (= node build.js; пишет dist/)
Все статические проверки:
    npm run verify                   (syntax, i18n, roadmap, генераторы, a11y, dist)
    npm test                         (verify + тесты фич из tests/)
Только аудит генераторов:
    npm run audit                    (68 тем, контракт вариантов/разбора)
Проверка живого сайта:
    npm run check:live               (= node tools/check-live.js; node .checklive.js тоже работает)
Деплой (production, REST API):
    npm run deploy                   (= node tools/deploy.js; branch обязательно НЕ указывать)
    powershell -File deploy-netlify.ps1   (build + deploy, опционально -DryRun/-SkipBuild)

Сайт: https://roaring-melba-8c60da.netlify.app/


Что это за проект
-----------------
Одностраничное SPA — образовательная платформа «Математика 10-11» для
подготовки к НМТ. Двуязычная (RU/UA), с PWA-оффлайном.

Архитектура
-----------
Mathcourse/
  index.html              разметка (без инлайн-кода)
  styles.css              основные стили (+ focus-visible)
  theme.css               light/dark + возрастные палитры (data-grade)
  i18n.js                 переводы RU/UA
  lessons.js              данные уроков + мини-проверки
  trainer.js              генераторы задач (LEVEL_DEFS, 68 тем)
  app.js                  state, навигация, рендеринг, прогресс, статистика
  sw.js                   service worker (кэш app shell)
  manifest.webmanifest    PWA-манифест
  build.js                сборка бандла в dist/ (computeBundle/build, экспорт)
  package.json            npm-скрипты (build/verify/test/audit/check:live/deploy)
  tools/
    lib.js                общие загрузчики LESSONS/ROADMAP/UI/LEVEL_DEFS
    verify.js             единый статический аудит
    check-live.js         e2e-проверки живого сайта (BASE через --base)
    deploy.js             production-деплой через Netlify REST API
  tests/
    run.js                раннер тестов
    minicheck.test.js     персист. мини-проверок, бейдж, индикатор
    trainer-stats.test.js статистика тренажёра, слабые темы, повторение
    trainer-question.test.js рендер вопроса, проверка/следующий, short-answer
  deploy-netlify.ps1      обёртка build + tools/deploy.js
  .checklive.js           тонкая обёртка -> tools/check-live.js

Уже реализовано
---------------
- Разбиение монолита на модули; index1.html удалён.
- Безопасный разбор ответов (без Function()/eval).
- PWA: service worker, кэш app shell, оффлайн, иконки.
- SEO/шаринг: meta description, Open Graph, favicon, og-иконка.
- Темы light/dark и возрастные палитры (1-4, 5-9, 10-11).
- Поиск по урокам и формулам; избранные формулы (закладки).
- Навигация «назад/вперёд» между уроками.
- Прогресс-бар модуля; отметка «урок пройден».
- Прогресс мини-проверок: бейдж на уроке + счётчик в сайдбаре
  (localStorage mc_mini), сохраняется между сессиями.
- Курс разделён на 10 модулей: 1–8 и 10 помечены как приоритетные для НМТ,
  модуль 9 (пределы, производная, интегралы) выделен как углублённый.
- Модуль 10 содержит шесть смешанных вариантов НМТ с заданиями по модулям
  1–8 и пошаговыми разборами на русском и украинском.
- Итоговые тесты тематических модулей генерируются автоматически (20 минут).
- Тренажёр: 68 тем, у каждой topic/format/solution (разбор ответа).
- Статистика тренажёра (localStorage mc_trainer): точность по темам,
  общая точность, панель на экране уровней; вклад «Повторить ошибки»
  (сессия по слабым темам с прогрессом и итогом).
- Экспорт формул/конспекта в PDF (клиентский генератор).
- Маскот «Квантик» с контекстными подсказками.
- Инфраструктура: единый `npm run verify`, тесты фич, REST-деплой,
  аудит связности уроков, модулей и тренажёра, проверка вариантов НМТ;
  базовый a11y-проход (focus-visible, aria-pressed, <nav>, progressbar,
  aria-hidden на декоративных глифах).

Оставшиеся рекомендации
-----------------------
P1 — Контент (главная цель платформы):
  1. Больше задач НМТ-формата в тренажёре (в т.ч. с параметром).
  2. Разборы НМТ-тестов прошлых лет (пошаговые решения).
  3. Видео-вставки (YouTube) для сложных тем.

P2 — Прогресс и геймификация:
  4. История ответов (динамика по датам) поверх готовой статистики.
  5. Сброс прогресса мини-проверок/тренажёра/уроков в настройках.
  6. Достижения/серии (streak) для мотивации.

P3 — UX:
  7. Печать/экспорт отдельного урока в PDF + print-стили.
  8. Повторное закрепление ошибок из мини-проверок (не только тренажёр).

P4 — Инфраструктура (частично сделано):
  9.  [сделано] deploy-netlify.ps1 -> REST tools/deploy.js.
  10. [сделано] аудит-скрипты в tools/, npm-скрипты; осталось CI
      (GitHub Actions: build + verify + test).
  11. [сделано] базовый a11y; при желании — контраст-аудит и ручная
      проверка скринридером.

Общая оценка
------------
Платформа в хорошем состоянии: чистая модульная архитектура, i18n,
безопасный ввод, PWA, продуманный контент, статистика тренажёра и
единая система проверок (verify/tests/e2e). Ключевые направления
дальше — наполнение НМТ-контентом и геймификация прогресса.
